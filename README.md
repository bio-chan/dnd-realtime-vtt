# ⚔️ D&D Table Helper

ผู้ช่วยสำหรับเล่นบอร์ดเกม D&D ออนไลน์แบบ real-time — ทอยลูกเต๋า 3D, การ์ดตัวละคร, ค่าพลัง, มอนสเตอร์, ร้านค้า, กระเป๋า และระบบเงิน

## เริ่มใช้งาน

```bash
npm install
npm start
```

เปิด `http://localhost:3000`

### บัญชี DM เริ่มต้น
| ชื่อผู้ใช้ | รหัสผ่าน |
|---|---|
| `dm` | `DungeonMaster2026` |

> เปลี่ยนได้ด้วย environment variable `DM_USERNAME` / `DM_PASSWORD` (มีผลตอนสร้างบัญชีครั้งแรก)

## ขั้นตอนการเล่น
1. **ล็อกอิน / สมัคร** — ทุกคนที่สมัครใหม่ได้ยศ **ผู้เล่น**
2. **สร้างตัวละคร** — เลือกเผ่า/อาชีพ (มีโบนัสเผ่า), ค่าพลัง 6 ด้าน (สุ่ม 4d6, ค่ามาตรฐาน, Point Buy), HP/SP/AC แนะนำอัตโนมัติ, สกิล, อัลติ, ภูมิหลัง, อุปกรณ์เริ่มต้น
3. **หน้าหลัก** — การ์ดตัวละครอยู่มุมขวา, ปุ่ม **หาห้อง** (กรอกรหัส) และ **สร้างห้อง** (เฉพาะ DM)
4. **ยศ DM** — DM มอบ/ถอดยศ DM ให้คนอื่นได้ที่แผง “จัดการยศผู้ใช้” ในหน้าหลัก (บัญชี DM หลักถอดยศไม่ได้)
5. **ในห้อง**
   - **ขวา**: การ์ดผู้เล่นแนวนอนเรียงลำดับ — DM ลากหรือกด ▲▼ จัดลำดับ, ⚙ จัดการ (ดาเมจ/ฮีล, สถานะ, เงิน, XP, มอบไอเทม, เชิญออก)
   - **ล่างกลาง**: ลูกเต๋า d4–d100, จำนวนลูก, โบนัส, ได้เปรียบ/เสียเปรียบ, ปุ่มลัด (เช็คค่าพลัง, Initiative, โจมตี, ดาเมจอาวุธ, Death Save), DM ทอยลับได้
   - **ล่างขวา**: ศัตรูในฉาก — DM ซัมมอนจากสมุดมอนสเตอร์หรือกำหนดเอง, ทอยโจมตี/ดาเมจในนามมอนสเตอร์, ซ่อน/เปิด HP, ปราบแล้วกด 🏆 แจกเงิน/XP/ของดรอป
   - **กลาง**: ลำดับเทิร์น (Initiative), บันทึกการทอย, แชท (`/r 2d6+3` เพื่อทอยสูตร), ประกาศเหตุการณ์
   - **ซ้าย**: ผู้เล่น — กระเป๋า (ใช้/สวมใส่/ขาย/ส่งให้เพื่อน/ทิ้ง), ร้านค้า; DM — ควบคุมฉาก (เหตุการณ์, พักสั้น/ยาว, ล็อกเทิร์น, XP), จัดการร้านค้า (ชื่อ ราคา สต็อก เอฟเฟกต์ ราคารับซื้อคืน), สมุดมอนสเตอร์ (ค่าพลัง รูป รางวัล ของดรอป)

## สิทธิ์ของผู้เล่นกับ DM
- **ผู้เล่น** ทำได้แค่: ทอยลูกเต๋า, โจมตีตามขั้นตอนในเทิร์นตัวเอง, ใช้/สวมไอเทม, ซื้อ ขาย และต่อราคากับร้านของ DM
- **DM** ควบคุมทุกอย่าง: เปิด/ปิดร้าน, ตั้งเกณฑ์การโจมตีและการต่อราคา, HP/สถานะ/เงิน/XP ของผู้เล่น, มอนสเตอร์, ลำดับเทิร์น
- ห้องหนึ่งมีผู้เล่นได้สูงสุด 8 คน (ไม่นับ DM) และระหว่างอยู่ในห้องผู้เล่นแก้ตัวละครไม่ได้

## ตัวเลือกตัวละคร
- **27 เผ่าพันธุ์** + กำหนดเอง และ **22 อาชีพ** + กำหนดเอง ทุกอันมีคำอธิบาย โบนัส บทบาทในทีม และระดับความยาก ดูได้ตอนสร้างตัวละคร (`public/data.js`)

## ร้านค้าและการต่อราคา
- ร้านค้าเป็นหน้าแยก DM เป็นคนเปิด/ปิด ตั้งชื่อร้าน ราคา สต็อก และราคารับซื้อคืน
- ผู้เล่นกด **ซื้อเลย** (ราคาเต็ม) หรือ **ต่อราคา**: DM ตั้งว่าต้องทอยได้เท่าไหร่และลดกี่ % แล้วผู้เล่นทอย d20 + CHA ถ้าผ่านได้ราคาลด ไม่ผ่านจ่ายราคาเต็ม

## ลูกเต๋าและความน่าจะเป็น
- สุ่มด้วย `crypto.randomInt` ของ Node (สุ่มแบบปลอดภัยระดับเข้ารหัส ไม่เอนเอียง) ทุกหน้ามีโอกาสเท่ากันพอดี 1/N
- หน้าจอแสดงโอกาสที่คำนวณแบบแม่นยำ (ไม่ใช่การประมาณ): โอกาสโดน, ดาเมจเฉลี่ย, ช่วงผลของลูกเต๋า, ได้เปรียบ/เสียเปรียบ (`public/dice-math.js`)
- `npm test` ทอยลูกเต๋าแต่ละแบบหลายแสนครั้งแล้วตรวจความเที่ยงด้วย chi-square และเทียบสูตรกับการไล่ทุกกรณี
